# Open a binary

Click a file in the Explorer:

- Linux and Unix: `.so`, `.so.1`, `.o`, `.ko`, `.elf`
- Windows: `.exe`, `.dll`, `.sys`, `.efi`, `.pyd`
- Apple: `.dylib`, universal binaries

Executables often have no extension. Right-click them and pick Open in ELF & PE Viewer.

The Overview tab shows the format, the architecture, the entry point and the libraries the file needs.
