# Imports, exports and symbols

- Imports: each function the file calls, with the library it comes from. For ELF files the library and the symbol version come from the GNU version tables; for Mach-O from the two-level namespace.
- Exports: what the file offers to others. PE exports show ordinals and forwarders.
- Symbols: the full symbol tables.

Type in the filter box to narrow a table, click a column name to sort, and use Copy rows to paste the table into a spreadsheet.
